This tests the ``MyList`` class defined in ``1-my_list.py``.

First, let's bring in the class::

    >>> MyList = __import__('1-my_list').MyList

An empty list should behave like a normal list::

    >>> my_list = MyList()
    >>> my_list
    []

Appending values works exactly like the builtin list type, and the
original insertion order is preserved when we just print it::

    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Calling print_sorted() prints an ascending sorted view of the list::

    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

The underlying list itself is not modified by print_sorted()::

    >>> print(my_list)
    [1, 4, 2, 3, 5]

A MyList is still a real list under the hood::

    >>> isinstance(my_list, list)
    True

Negative numbers and duplicates sort correctly too::

    >>> another = MyList()
    >>> another.append(-3)
    >>> another.append(0)
    >>> another.append(2)
    >>> another.append(2)
    >>> another.append(-10)
    >>> another.print_sorted()
    [-10, -3, 0, 2, 2]
